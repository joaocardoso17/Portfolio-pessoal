# Portfólio — João Cardoso 🚀

Protótipo do meu portfólio pessoal, desenvolvido com uma identidade visual inspirada em interfaces tech/cyberpunk (tons de ciano e magenta sobre fundo escuro, tipografia com elementos de terminal). O objetivo é apresentar quem eu sou, minhas stacks e habilidades, e os principais projetos que já desenvolvi como estudante de Análise e Desenvolvimento de Sistemas (ADS).

Este repositório reúne o **protótipo visual/interativo** da página, criado no Figma, junto com os prints das telas para consulta rápida sem precisar abrir o Figma.

## 🧩 Estrutura da página

- **Início** — apresentação pessoal e chamadas para ação (Ver Projetos / Contato)
- **Skills** — stacks e habilidades técnicas e comportamentais
- **Projetos** — repositório dos principais projetos desenvolvidos
- **Contato** — formas de conexão (GitHub, LinkedIn, etc.)
